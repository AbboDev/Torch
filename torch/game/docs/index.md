# torch — composed engine

**Start with [make-a-2d-game.md](make-a-2d-game.md), and read it whole:** the whole surface in one page. The other pages are reference: look a thing up there when the page sends you, or for a pack you added.

This game composes `core-2d`, which brings `render-auto`, `world-side`, `world-screen`, `rig-follow`, `maths`, `color`, `audio`, `ui`, `tween`, `backdrops`, `backdrop-sky`, `backdrop-stars`, `render-texture`, `particle-textures`, `particles-2d`, `feel`, `collision`, `pointer`; and `controls-2d`, `typography`, `save`, `ui-skins`, `ui-skin-candy`, `controls-touch`, `bars`, `transition`.
Nothing else exists. Import `game` from `./engine.js`.
